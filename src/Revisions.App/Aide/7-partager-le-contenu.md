# Partager le contenu avec un camarade

Tu peux donner tous tes cours à un camarade du CNED en **un seul fichier**, et il peut te donner les siens. Chacun garde **sa propre progression** : elle n'est jamais dans le fichier.

> **Rappel :** les cours du CNED sont réservés à leurs destinataires, à usage privé. Ne les partage qu'avec tes camarades, et ne les publie jamais (réseaux sociaux, GitHub, etc.).

### Envoyer mon contenu

1. Ouvre **Réglages**, carte **Partager avec un camarade**.
2. Coche **Inclure aussi les documents d'origine** si tu veux que ton camarade puisse ouvrir les PDF (« Voir le PDF »). La taille est indiquée à côté : c'est lourd, compte plusieurs minutes.
3. Clique sur **Exporter mon contenu…**, choisis où enregistrer le fichier `.atome`, puis envoie-le (clé USB, lien de partage…).

Le fichier contient les packs, le planning et, si tu l'as coché, les documents. Il ne contient **ni ta base, ni tes réglages, ni ton historique**.

### Recevoir le contenu d'un camarade

1. Clique sur **Importer du contenu** (au premier lancement, le bouton est en grand dans la Bibliothèque ; sinon dans **Réglages**).
2. Choisis le fichier `.atome`. L'application vérifie qu'il est valide avant d'y toucher.
3. Le contenu est rangé dans `{{DOSSIER_DONNEES}}\contenu`. Si tu avais déjà un dossier de packs, l'application te demande de **fusionner** (on ajoute au dossier existant) ou de **remplacer** (on utilise le nouveau dossier, l'ancien n'est pas effacé).
4. Un récapitulatif indique le nombre de packs et de cartes, et si les documents sont inclus.

Importer une nouvelle version du même contenu met les cours à jour **sans toucher à ta progression** : tes cartes déjà révisées gardent leur historique.
