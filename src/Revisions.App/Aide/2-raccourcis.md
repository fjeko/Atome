# Raccourcis clavier

Une session peut se faire entièrement au clavier.

### Pendant une session

| Touche | Action |
| --- | --- |
| **Espace** | voir la réponse, ou l'étape suivante d'un exercice |
| **1**, **2**, **3**, **4** | noter : Raté, Difficile, Bien, Facile (rangée du haut, avec ou sans Maj, ou pavé numérique) |
| **A** à **E** | choisir une réponse de QCM |
| **Entrée** | la suite logique : révéler, continuer, ou noter « Bien » |
| **S** | signaler une erreur dans la carte (pas dans la zone de réponse écrite) |
| **Échap** | faire une pause : Atome demande confirmation, ce qui est fait reste enregistré (Échap à nouveau pour continuer) |
| **Ctrl + Z** | annuler ta dernière note si tu t'es trompé de bouton (le petit lien **Annuler** fait pareil) : tu reviens à la carte précédente, comme avant la note |

### Écrire sa réponse (cartes « question »)

La zone de texte sous la carte est facultative. Zone vide, **Espace** voit la réponse comme d'habitude ; dès que tu as écrit quelque chose, les touches écrivent du texte et c'est **Entrée** qui valide.

| Touche | Action |
| --- | --- |
| **Tab** | entrer dans la zone pour écrire |
| **Entrée** (ou **Ctrl + Entrée**) | voir la réponse et la comparer à la tienne |
| **Maj + Entrée** | saut de ligne dans ta réponse |
| **Échap** | sortir de la zone (ton texte est gardé) |

### Écrire du code (cartes qui demandent du code)

Quand une carte te demande d'écrire du code (« Écris… », « Réécris… avec un `switch` »), la zone devient un petit éditeur, avec le libellé **Écris ton code ici**. Pas besoin qu'il compile : c'est l'idée qui compte. Une fois la correction affichée, ton code apparaît à côté (ou au-dessus sur un écran étroit) pour comparer.

| Touche | Action |
| --- | --- |
| **Tab** (hors de la zone) | entrer dans la zone pour écrire |
| **Entrée** | nouvelle ligne, avec la même indentation (un cran de plus après `{` ou `:`) |
| **Tab** / **Maj + Tab** | indenter / désindenter de 4 espaces (toutes les lignes sélectionnées) |
| **Ctrl + Entrée** | voir la correction (ou le bouton **Voir la correction**) |
| **Échap** | sortir de la zone (ton code est gardé) |

### En lecture

| Touche | Action |
| --- | --- |
| **←** et **→** | section précédente, section suivante |

### En TD en groupe

| Touche | Action |
| --- | --- |
| **Tab**, flèches | passer d'une case de la grille à l'autre |
| **Ctrl + Entrée** | vérifier ses réponses |
| **Espace** | « go », puis étape suivante de la correction |
| **Entrée** (hors des cases) | la suite logique : go, vérifier, étape suivante, exercice suivant |
| **I** (hors des cases) | indice |

### Calculatrice (exercices de maths)

| Touche | Action |
| --- | --- |
| **Ctrl + K** | ouvrir la calculatrice, y revenir, ou la fermer |
| **Entrée** | calculer |
| **↑** et **↓** | revenir sur les calculs précédents |
| **Échap** | fermer la calculatrice et reprendre l'exercice |

### Partout

| Touche | Action |
| --- | --- |
| **F11** | plein écran (pratique en session pour se concentrer) ; **F11** ou **Échap** pour en sortir |
| **Tab** | passer d'un bouton à l'autre : l'élément choisi est toujours entouré d'un cadre de couleur |
